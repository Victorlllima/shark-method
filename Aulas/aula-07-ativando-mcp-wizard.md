# 📺 ROTEIRO: AULA 7 - ATIVANDO OS SENTIDOS (A MISSÃO DAS 4 CHAVES)

**⏱️ Duração Estimada:** 15-20 minutos  
**🎯 Objetivo:** Coletar as credenciais (chaves) e configurar o sistema via Wizard usando comandos de linguagem natural.

## 1. PREPARAÇÃO: A MISSÃO DAS 4 CHAVES 🗝️

> *"Shark, antes de ligarmos a máquina, precisamos do combustível.
>
> Para os seus agentes interagirem com o mundo, eles precisam de autorização. Nós chamamos isso de **Tokens** ou Chaves de API.
>
> Mantenha um Bloco de Notas aberto aí do lado. Sua primeira (e única) missão manual é obter as 4 Chaves do Poder. Sem elas, seus agentes continuam isolados."*
>
> **(Mostre na tela onde clicar - Rápido e Direto)**
>
> *   **🗝️ Chave 1: GitHub (O Armazém)**
>     *   *Onde:* Settings > Developer Settings > Personal Access Tokens (Tokens Clássicos).
>     *   *Permissões:* Marque apenas 'repo'.
>     *   *Pra que serve:* Pro Atlas salvar seu código na nuvem.
>
> *   **🗝️ Chave 2: Supabase (O Cofre Global)**
>     *   *Onde:* Account Settings > Access Tokens.
>     *   *Pra que serve:* É a chave mestra que permite ao Hades criar projetos, bancos de dados e gerenciar tudo sem restrições.
>
> *   **🗝️ Chave 3: Firecrawl (O Extrator)**
>     *   *Onde:* Firecrawl.dev > API Key.
>     *   *Pra que serve:* Enquanto a Ravena "olha" o site, o Firecrawl "extrai os dados". Ele pega o conteúdo de qualquer página e transforma em banco de dados para a Shiva usar. É inteligência pura.
>
> *   **🗝️ Chave 4: Vercel (O Palco)**
>     *   *Onde:* Account Settings > Tokens.
>     *   *Pra que serve:* Pra colocar seu projeto no ar.
>
> *"Pegou todas? Colocou no bloco de notas? Ótimo. Agora você está armado. Esqueça o navegador, vamos voltar pra base."*

## 2. A INVOCACÃO: SEM CÓDIGO, SÓ COMANDO 🗣️

> *"Lembra que eu disse que a gente não ia ficar digitando código estranho? Pois é.
>
> Para facilitar sua vida e evitar qualquer erro de digitação, eu preparei um **Guia de Comandos** especial.
>
> Vá até a pasta `docs` no seu explorador de arquivos (lado esquerdo) e abra o arquivo `shark-commands.html`. Ele vai abrir no seu navegador com todos os comandos prontos.
>
> Na seção **Aula 7**, clique no botão **Copiar Prompt**.
>
> Agora volte no Chat do Antigravity (na direita), cole e dê a ordem para a IA:"*

**O Prompt:**
> *"Atlas, por favor, rode o script `scripts/setup-wizard.js` para iniciarmos a configuração."*

> *"Perceba o que acontece. A IA vai entender o seu pedido, encontrar o arquivo correto na pasta e te perguntar: 'Deseja executar este comando?'.
>
> Você só precisa clicar no botão de **Run** (Executar).
>
> Isso é a essência do Vibecoding: Você dá a intenção, a IA lida com a sintaxe."*

## 3. O RITUAL: O MAGO APARECE 🧙‍♂️

> *"Assim que você autorizar, o Terminal vai abrir sozinho lá embaixo e te mostrar uma mensagem mágica:
>
> `🟣 [SHIVA]: Wizard de Setup do Protocolo S.H.A.R.K. iniciado!`
>
> E vai te dar um link: `http://localhost:3008`.
>
> Segura o `Ctrl` e clica nesse link. O painel de controle vai abrir no seu navegador."*

## 4. O PAINEL DE CONTROLE: PREENCHENDO AS CHAVES 🎛️

**(Visualização Mental: O aluno vê uma tela futurista local com campos para as chaves)**

> *"Bem-vindo à Interface de Conexão Neural.
>
> Lembra das chaves que você anotou no bloco de notas? É agora.
>
> *   Cola a chave do GitHub no campo vermelho...
> *   A do Supabase no campo verde...
> *   A do Firecrawl no campo laranja...
>
> Viu que ficou verdinho na hora? O Wizard está testando a conexão em tempo real. Você não precisa adivinhar se a chave está certa, ele te avisa.
>
> Tudo verde? Então clique no botão **SALVAR E INICIAR AMBIENTE**."*

## 5. O GRANDE FINAL: A CONFIRMAÇÃO ✅

> *"Volta pro Antigravity. Olha a festa acontecendo no terminal.
>
> Você vai ver mensagens confirmando que as chaves foram guardadas num cofre digital (`.env`) e que o sistema está online.
>
> O Atlas vai dizer: `🚀 [HADES]: Iniciando propulsores...`
>
> Pronto. Shark, respira fundo. Você acabou de integrar 4 plataformas gigantes em um único sistema local usando apenas uma frase no chat.
>
> Seus agentes agora têm olhos, ouvidos e mãos. A oficina está pronta. Na próxima aula, vamos fazer o check-up final."*
