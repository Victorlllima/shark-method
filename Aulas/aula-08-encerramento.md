# 📺 ROTEIRO: AULA 8 - O GRANDE TESTE (CHECK-UP FINAL)

**⏱️ Duração Estimada:** 5-7 minutos  
**🎯 Objetivo:** Validar se o ambiente está 100% operacional através de uma conversa com a Shiva.

## 1. O MOMENTO DA VERDADE 🕵️‍♂️

> *"Shark, agora é a hora da verdade. A gente montou a oficina, trouxe a equipe, conectou as chaves...
>
> Mas será que esse foguete liga?
>
> Não vamos rodar scripts de teste chatos. Vamos fazer o que viemos fazer aqui: CONVERSAR com a inteligência."*

## 2. AÇÃO: O CHECK-UP VIA CHAT 💬

**O Prompt:**  
> *"Vá no Chat do Antigravity e digite para a Shiva:"*

> `Shiva, faça um check-up geral no meu ambiente. Verifique se os agentes estão ativos e se as conexões externas (GitHub, Supabase) estão funcionando.`

**(Nota Técnica: A Shiva invocará o script `shark-status` internamente)**

> *"Observe a resposta dela. Ela não vai só dizer 'OK'. Ela vai testar cada conexão:
>
> *   ✅ **GitHub:** Conectado (Atlas pronto para salvar)
> *   ✅ **Supabase:** Conectado (Hades pronto para modelar)
> *   ✅ **Firecrawl:** Conectado (Ravena pronta para ler)
>
> Se aparecer algum **X** vermelho, ela mesma vai te dizer: 'Shark, a chave do Supabase parece inválida. Rode o Wizard de novo'.
>
> É isso que significa ter um **Parceiro de Código**. Ele não te deixa errar sozinho."*

## 3. REFLEXÃO: O QUE VOCÊ TEM NAS MÃOS 💎

> *"Olha para essa tela agora. Sério. Para tudo e olha.
>
> Há algumas aulas atrás, isso era só um editor de texto vazio. Agora, é uma extensão do seu cérebro conectada ao mundo.
>
> Você tem a Shiva para pensar.  
> O Hades para arquitetar.  
> O Atlas para construir.  
> A Ravena para testar.  
> O Kerberos para proteger.
>
> Você não está mais sozinho. Aquele sentimento de travar na frente do código? Acabou. Aquela dúvida de 'por onde eu começo?' Acabou."*

## 4. O FUTURO: O QUE VEM NO MÓDULO 2 🚀

> *"E agora? Agora começa a brincadeira de verdade.
>
> No próximo módulo, a gente vai usar essa estrutura para tirar uma ideia do papel. Vamos criar o **RedFlix** (ou o nome que você quiser dar).
>
> Você vai ver a Shiva te entrevistando, o Hades desenhando o banco de dados e o Atlas escrevendo código enquanto você decide as regras do negócio.
>
> Descansa, comemora. Tira um print da sua tela com tudo verde e manda lá no grupo. Porque amanhã... amanhã a gente começa a construir o futuro.

> Te vejo no Módulo 2, Shark."*
