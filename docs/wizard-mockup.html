Cofre de Código (GitHub)

O GitHub é como um "Cofre Digital". É lá que seu projeto fica salvo e onde cada pequena mudança é registrada com segurança total.

1 No seu GitHub, clique na sua foto de perfil (canto superior direito) e vá em Settings.
2 No menu lateral esquerdo, desça até o final e clique em Developer settings.
3 Clique em Personal access tokens > Tokens (classic) e gere um novo token marcando a caixinha 'repo'.
