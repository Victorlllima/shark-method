## 📍 AULA 2: O QUE É UMA IDE?
**⏱️ Duração:** 7 minutos

### Objetivo
Desmistificar o conceito de IDE para quem nunca ouviu falar.

### Tópicos
- O que significa IDE (sem jargão)
- Para que serve
- Metáfora da "oficina do criador"

### 💬 Fala Pronta - Explicando IDE

> *"Antes da gente baixar qualquer coisa, eu preciso te explicar um conceito importante. Você já deve ter ouvido falar que programadores usam 'programas especiais' para escrever código, né? Esses programas têm um nome: IDE.*
>
> *IDE é uma sigla em inglês que significa 'Ambiente de Desenvolvimento Integrado'. Mas esquece esse nome complicado. Pensa assim: se você fosse um pintor, você precisaria de um ateliê, certo? Um lugar com cavalete, tintas organizadas, pincéis, boa iluminação... A IDE é isso, só que para quem cria software.*
>
> *É o seu ateliê digital. É onde você escreve, organiza, testa e dá vida às suas criações. E a boa notícia? O programa que a gente vai usar é gratuito e foi feito para facilitar a sua vida."*

### 💬 Fala Pronta - Reforço da Metáfora

> *"Olha, toda profissão criativa tem seu espaço de trabalho especializado. O chef tem a cozinha com os utensílios organizados. O músico tem o estúdio com os instrumentos. O arquiteto tem o escritório com as pranchetas. E quem cria tecnologia? Tem a IDE. É simples assim."*

## 📍 AULA 5: ENTENDENDO GIT E GITHUB
**⏱️ Duração:** 8 minutos

### Objetivo
Explicar Git e GitHub de forma acessível, preparando para a importação.

### Tópicos
- O que é Git (a máquina do tempo)
- O que é GitHub (a nuvem dos projetos)
- Por que isso importa para nós

### 💬 Fala Pronta - Explicando Git

> *"Antes de a gente trazer o método pro seu computador, preciso te explicar mais dois conceitos. Prometo que é a última dose de teoria antes da prática!*
>
> *Primeiro: Git. O Git é tipo uma máquina do tempo para os seus arquivos. Imagina que você está escrevendo um livro. Aí você faz uma mudança grande num capítulo, mas depois se arrepende. Com o Git, você consegue voltar pra versão anterior como se a mudança nunca tivesse acontecido.*
>
> *Programadores usam isso o tempo todo porque criar software é um processo de muitas tentativas. O Git guarda o histórico de tudo, então você nunca perde nada e sempre pode voltar atrás."*

### 💬 Fala Pronta - Explicando GitHub

> *"Agora, o GitHub. Se o Git é a máquina do tempo, o GitHub é a nuvem onde você guarda essa máquina do tempo.*
>
> *Pensa assim: você pode ter fotos salvas no seu computador, certo? Mas se o seu computador quebrar, você perde tudo. Aí você usa o Google Fotos ou o iCloud pra guardar na nuvem. O GitHub é a mesma ideia, só que para projetos de programação.*
>
> *E tem um bônus: o GitHub não serve só pra guardar. Ele também permite que outras pessoas vejam e usem seus projetos. É uma rede social de código. E é lá que o nosso método S.H.A.R.K. está guardado, esperando pra vir pro seu computador."*

### 💬 Fala Pronta - Conectando os Conceitos

> *"Então, resumindo: o Git é o sistema que controla as versões. O GitHub é o lugar na internet onde essas versões ficam guardadas. E a gente vai usar os dois agora pra trazer o método pro seu ambiente."*

## 📍 AULA 6: IMPORTANDO O MÉTODO S.H.A.R.K.
**⏱️ Duração:** 12 minutos

### Objetivo
Clonar o repositório do método para dentro do ambiente do aluno.

### Tópicos
- Abrir o terminal no Antigravity
- Executar o comando de clonagem
- Rodar o script de instalação
- Reiniciar o programa

### 💬 Fala Pronta - Preparando para Importar

> *"Chegou a hora mais emocionante! A gente vai trazer o método S.H.A.R.K. lá do GitHub pra dentro do seu Antigravity. É como ir na loja, pegar o produto e trazer pra casa. Só que a loja é a internet e o produto é gratuito."*

### Passo a Passo Detalhado

#### PASSO 1: Abrir o Terminal no Antigravity

### 💬 Fala Pronta - Abrindo Terminal

> *"No Antigravity, tem uma área chamada 'Terminal'. É um lugar onde você digita comandos pro computador executar. Pra abrir, você pode ir no menu 'Terminal' lá em cima e clicar em 'New Terminal'. Ou, se quiser ser mais rápido, aperta Ctrl + aspas simples no seu teclado. Vai aparecer uma área preta na parte de baixo da tela.*
>
> *Não se assuste com essa tela preta. É só uma forma diferente de conversar com o computador. Em vez de clicar em botões, você escreve o que quer que ele faça."*

#### PASSO 2: Clonar o Repositório

**Comando:**
```powershell
git clone https://github.com/Victorlllima/shark-method.git $HOME/.gemini-shark-temp
```

### 💬 Fala Pronta - Explicando o Comando

> *"Agora você vai digitar um comando. Não precisa decorar, só copia exatamente o que eu vou mostrar na tela. Esse comando faz o seguinte: ele vai no GitHub, pega todo o conteúdo do método S.H.A.R.K. e baixa pra uma pasta temporária no seu computador. É o famoso 'clonar' - você está fazendo uma cópia do projeto pra você."*

#### PASSO 3: Executar o Script de Instalação

**Comando:**
```powershell
cd $HOME/.gemini-shark-temp; .\install.ps1
```

### 💬 Fala Pronta - Instalando o Método

> *"Perfeito! Agora a gente precisa dizer pro computador: 'Olha, pega o que você baixou e instala direitinho no lugar certo'. Pra isso, a gente vai rodar o script de instalação que já vem junto no pacote. Copia esse segundo comando e cola no terminal. Ele vai organizar tudo automaticamente pra você."*

#### PASSO 4: Reiniciar o Antigravity

### 💬 Fala Pronta - Finalizando

> *"Maravilha! Agora a gente precisa reiniciar o Antigravity pra ele reconhecer as novidades. É tipo quando você instala um aplicativo no celular e ele pede pra reiniciar. Fecha o programa completamente e abre de novo. Quando ele voltar, o método S.H.A.R.K. já vai estar instalado e funcionando."*
