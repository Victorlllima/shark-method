## 🔐 VAULT LOCAL — COFRE DE CREDENCIAIS DO PROJETO

### Por que criar o vault?

Os agentes do S.H.A.R.K. precisam consultar tokens e chaves durante a execução — GitHub token, Supabase key, Stripe key, etc. Sem um cofre local, o [NOME] teria que colar credenciais manualmente toda vez. Com o vault, os agentes consultam silenciosamente sem interromper o fluxo.

### Quando criar?

**OBRIGATÓRIO** ao iniciar qualquer novo projeto. Criar durante a Fase 01 (Fundação), antes de qualquer configuração de MCP ou deploy.

### Como criar (instruções para Atlas executar):

#### Windows — DPAPI (Data Protection API)
```powershell
# O DPAPI criptografa usando a conta do usuário Windows como chave.
# Só o próprio usuário, na mesma máquina, consegue descriptografar.

$vaultDir = "$env:USERPROFILE\.shark\vaults\[SLUG_DO_PROJETO]"
New-Item -ItemType Directory -Force -Path $vaultDir | Out-Null

# Função para salvar credencial criptografada
function Save-SharkCredential {
    param([string]$Key, [string]$Value)
    $encrypted = [System.Security.Cryptography.ProtectedData]::Protect(
        [System.Text.Encoding]::UTF8.GetBytes($Value),
        $null,
        [System.Security.Cryptography.DataProtectionScope]::CurrentUser
    )
    $b64 = [Convert]::ToBase64String($encrypted)
    Set-Content -Path "$vaultDir\$Key.vault" -Value $b64
    Write-Host "✅ Credencial '$Key' salva com criptografia DPAPI."
}

# Função para ler credencial
function Get-SharkCredential {
    param([string]$Key)
    $b64 = Get-Content -Path "$vaultDir\$Key.vault"
    $encrypted = [Convert]::FromBase64String($b64)
    $bytes = [System.Security.Cryptography.ProtectedData]::Unprotect(
        $encrypted, $null,
        [System.Security.Cryptography.DataProtectionScope]::CurrentUser
    )
    return [System.Text.Encoding]::UTF8.GetString($bytes)
}

# Exemplo de uso:
# Save-SharkCredential -Key "github_token" -Value "ghp_..."
# $token = Get-SharkCredential -Key "github_token"
```

#### macOS — Keychain
```bash
# O Keychain do macOS é o cofre nativo do sistema.
# Criptografado com a senha de login do usuário.

VAULT_SERVICE="shark-[SLUG_DO_PROJETO]"

# Salvar credencial
save_shark_credential() {
    local key="$1"
    local value="$2"
    security add-generic-password \
        -s "$VAULT_SERVICE" \
        -a "$key" \
        -w "$value" \
        -U 2>/dev/null
    echo "✅ Credencial '$key' salva no Keychain."
}

# Ler credencial
get_shark_credential() {
    local key="$1"
    security find-generic-password \
        -s "$VAULT_SERVICE" \
        -a "$key" \
        -w 2>/dev/null
}

# Exemplo de uso:
# save_shark_credential "github_token" "ghp_..."
# TOKEN=$(get_shark_credential "github_token")
```

#### Linux — Secret Service (libsecret / GNOME Keyring)
```bash
# Usa o Secret Service API — disponível no GNOME e KDE.
# Requer: sudo apt install libsecret-tools (ou equivalente)

VAULT_COLLECTION="shark-[SLUG_DO_PROJETO]"

# Salvar credencial
save_shark_credential() {
    local key="$1"
    local value="$2"
    secret-tool store \
        --label="Shark/$VAULT_COLLECTION/$key" \
        project "$VAULT_COLLECTION" \
        key "$key" <<< "$value"
    echo "✅ Credencial '$key' salva no Secret Service."
}

# Ler credencial (sem prompt ao usuário)
get_shark_credential() {
    local key="$1"
    secret-tool lookup project "$VAULT_COLLECTION" key "$key" 2>/dev/null
}

# Fallback: arquivo criptografado com openssl (se sem Secret Service)
save_shark_credential_fallback() {
    local key="$1"
    local value="$2"
    local vault_dir="$HOME/.shark/vaults/$VAULT_COLLECTION"
    mkdir -p "$vault_dir"
    echo "$value" | openssl enc -aes-256-cbc \
        -pbkdf2 -iter 100000 \
        -pass pass:"$(id -u)-$(hostname)" \
        -out "$vault_dir/$key.enc" 2>/dev/null
    echo "✅ Credencial '$key' salva com OpenSSL AES-256."
}
```

