### FASE 4 — AUDITORIA SUPABASE (SQL direto)

Execute estas queries via Supabase MCP ou SQL Editor:

```sql
-- 1. TABELAS SEM RLS (REPROVAÇÃO AUTOMÁTICA se houver)
SELECT schemaname, tablename, rowsecurity
FROM pg_tables
WHERE schemaname = 'public' AND rowsecurity = false;

-- 2. TABELAS COM RLS MAS SEM POLICIES (bug de lógica — inacessível)
SELECT t.tablename
FROM pg_tables t
LEFT JOIN pg_policies p ON t.tablename = p.tablename
WHERE t.schemaname = 'public' AND t.rowsecurity = true AND p.tablename IS NULL;

-- 3. POLICIES COM user_metadata (INSEGURO — usuário pode alterar)
SELECT policyname, tablename, qual
FROM pg_policies
WHERE qual LIKE '%user_metadata%' OR with_check LIKE '%user_metadata%';

-- 4. LISTAR TODAS AS POLICIES PARA AUDITORIA
SELECT schemaname, tablename, policyname, permissive, roles, cmd, qual
FROM pg_policies WHERE schemaname = 'public' ORDER BY tablename;

-- 5. FUNCTIONS COM SECURITY DEFINER (bypassam RLS)
SELECT routine_name, security_type
FROM information_schema.routines
WHERE routine_schema = 'public' AND security_type = 'DEFINER';
```

#### 6.3 — CSRF (Cross-Site Request Forgery)

```javascript
// Logar como usuário, capturar endpoint de mutação via browser_network_requests()
// Tentar replay da requisição sem token CSRF via browser_evaluate():
browser_evaluate({
  script: `
    fetch('/api/user/update', {
      method: 'POST',
      credentials: 'include',
      headers: {'Content-Type': 'application/json'},
      body: JSON.stringify({name: 'HACKED'})
    }).then(r => ({status: r.status, ok: r.ok}))
  `
})
// Se retornar 200 = CSRF vulnerável
```

#### 6.4 — IDOR (Insecure Direct Object Reference)

```javascript
// Logar como User A, obter ID de um recurso próprio
// Testar acesso a recursos de outros usuários:
browser_evaluate({
  script: `
    const results = []
    for(let i = 1; i <= 10; i++) {
      const r = await fetch('/api/resource/' + i, {credentials:'include'})
      results.push({id: i, status: r.status})
    }
    return results
  `
})
// Se retornar 200 para IDs que não são do usuário = IDOR confirmado
```
