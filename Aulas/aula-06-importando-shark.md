# 📺 ROTEIRO: AULA 6 - O DELIVERY DA OFICINA (IMPORTANDO O MÉTODO)

**⏱️ Duração Estimada:** 10-15 minutos  
**🎯 Objetivo:** Preparar a máquina local para receber a inteligência dos Agentes via comando simples.

## 1. INTRODUÇÃO: O CAMINHÃO CHEGOU �

> *"Fala, Shark!
>
> Nas últimas aulas, a gente preparou o terreno. Instalamos o Antigravity, conhecemos nossa nova casa... mas se você olhar bem, a oficina ainda tá vazia.
>
> É como se você tivesse alugado um galpão incrível, mas não tivesse trazido as ferramentas, as máquinas, nem a sua equipe.
>
> Hoje é o dia da mudança. Sabe aquele caminhão de entrega chegando com tudo o que você comprou? É exatamente isso que vamos fazer agora.
>
> Vamos trazer a **Inteligência** para dentro da máquina."*

## 2. PREPARAÇÃO: O TERRENO DA OFICINA 🏗️

> *"Antes de trazer a equipe, a gente precisa preparar o terreno. Não vamos jogar nossas ferramentas em qualquer lugar.
>
> Vamos criar uma pasta especial na raiz do seu computador para guardar todos os seus projetos Vibecoding.
>
> No Terminal (lá embaixo), digita o seguinte comando e dá Enter (pode copiar daqui):*
>
> ```powershell
> cd C:\; mkdir Vibecoding; cd Vibecoding
> ```
>
> *Pronto. Agora seu terminal deve estar mostrando algo como `PS C:\Vibecoding>`. Estamos na base."*

## 3. AÇÃO: O PRIMEIRO PASSO (O GIT CLONE) 🧬

> *"Agora que o terreno tá pronto, vamos trazer a estrutura.
>
> Lembra que eu prometi que você quase não ia precisar digitar comandos complicados?
>
> Eu cumpri. A maioria deles vai estar num Guia Especial que você vai baixar agora.
>
> Mas para trazer esse Guia (e todo o resto da oficina) para o seu computador, você precisa dar o **Primeiro Passo Manual**. É um rito de passagem.
>
> Vai aqui embaixo, na descrição da aula (ou nos comentários fixados), e copia o comando que eu deixei lá.
>
> **O Comando que você vai usar:**
> ```powershell
> git clone https://github.com/Victorlllima/shark-method.git
> ```
>
> *(Nota para o Victor: Como você já tem o método instalado, use este comando modificado para não quebrar seu ambiente, mas explique para o aluno que é só para demonstração)*:
> ```powershell
> git clone https://github.com/Victorlllima/shark-method.git shark-method-temp
> ```
>
> Copiou? Agora volta para o Antigravity."*

## 4. O TERMINAL: O SEU RÁDIO COMUNICADOR 📟

> *"Lá embaixo, tem uma janelinha chamada **Terminal**. Pensa nela como o interfone da portaria.
>
> Clica ali, cola o comando que você copiou (Ctrl+V).
>
> Antes de dar Enter, olha o que você está pedindo pro computador fazer:
>
> 1.  **`git`**: É o entregador. Você está chamando o serviço de entregas.
> 2.  **`clone`**: É o pedido. Você está dizendo "Quero uma cópia exata do que tem lá no armazém".
> 3.  **`https://...`**: É o endereço do armazém. Onde fica o projeto original.
> 4.  **(vazio)**: É o destino. Se você não falar nada, ele cria uma pasta com o nome do projeto. (Eu vou digitar um nome extra aqui só porque já tenho a pasta original, mas você não precisa).
>
> Agora sim. Pode apertar **Enter**.
>
> Não pisca.
>
> Você vai ver um monte de letrinhas correndo na tela. Não se assusta! Isso não é erro. Isso é a sua equipe chegando.
>
> O sistema está baixando a **Shiva**, o **Hades**, o **Atlas**... e junto com eles, o seu **Livro de Feitiços** (o Guia de Comandos)."*

## 4. CONHECENDO O GUIA DE COMANDOS 📖

> *"Quando as letras pararem de correr, olha para a barra lateral esquerda (o Explorador de Arquivos).
>
> Apareceu uma pasta nova? Ótimo.
>
> Agora sim, sua oficina tem ferramentas.
>
> Dentro dessa pasta, procura a subpasta `docs` e abre o arquivo `shark-commands.html`.
>
> Ele vai abrir no seu navegador. Esse é o seu **Painel de Controle** daqui pra frente.
>
> Pra tudo o que a gente for fazer nas próximas aulas (instalar, configurar, validar), você só vai clicar em **Copiar** nesse guia e colar no chat. Sem decorar nada."*

## 4. REINICIALIZAÇÃO: LIGANDO A CHAVE GERAL ⚡

> *"Quando as letras pararem de correr, significa que a mudança terminou.
>
> Mas pra casa nova funcionar, a gente precisa 'religar a chave geral'.
>
> Fecha o Antigravity completamente. Respira fundo. E abre de novo.
>
> Quando ele voltar, ele já não é mais o mesmo. Ele agora tem superpoderes."*

## 5. O GRANDE TESTE: ACORDANDO A SHIVA 💜

> *"Vamos ver se funcionou?
>
> No chat do Antigravity, eu quero que você digite só o nome dela, tudo minúsculo:
>
> `shiva`
>
> Se ela responder se apresentando... Parabéns, Shark.
>
> Sua oficina está oficialmente aberta para negócios. O Método S.H.A.R.K. está vivo na sua máquina.
>
> Na próxima aula, a gente vai entregar as chaves do cofre para eles."*
