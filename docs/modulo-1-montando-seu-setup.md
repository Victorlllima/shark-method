## 📍 AULA 2: O QUE É UMA IDE?
**⏱️ Duração:** 7 minutos

### Objetivo
Desmistificar o conceito de IDE para quem nunca ouviu falar.

### Tópicos
- O que significa IDE (sem jargão)
- Para que serve
- Metáfora da "oficina do criador"
- Exemplos de profissões e seus ambientes

### 💬 Fala Pronta - Explicando IDE

> *"Antes da gente baixar qualquer coisa, eu preciso te explicar um conceito importante. Você já deve ter ouvido falar que programadores usam 'programas especiais' para escrever código, né? Esses programas têm um nome: IDE.*
>
> *IDE é uma sigla em inglês que significa 'Ambiente de Desenvolvimento Integrado'. Mas esquece esse nome complicado. Pensa assim: se você fosse um pintor, você precisaria de um ateliê, certo? Um lugar com cavalete, tintas organizadas, pincéis, boa iluminação... A IDE é isso, só que para quem cria software.*
>
> *É o seu ateliê digital. É onde você escreve, organiza, testa e dá vida às suas criações. E a boa notícia? O programa que a gente vai usar é gratuito e foi feito para facilitar a sua vida."*

### 💬 Fala Pronta - Reforço da Metáfora

> *"Olha, toda profissão criativa tem seu espaço de trabalho especializado. O chef tem a cozinha com os utensílios organizados. O músico tem o estúdio com os instrumentos. O arquiteto tem o escritório com as pranchetas. E quem cria tecnologia? Tem a IDE. É simples assim."*

## 📍 AULA 5: GIT, GITHUB E GITFLOW
**⏱️ Duração:** 10 minutos

### Objetivo
Explicar Git, GitHub e o conceito de Gitflow de forma acessível.

### Tópicos
- O que é Git (a máquina do tempo)
- O que é GitHub (a nuvem dos projetos)
- O que é Gitflow (as pistas do aeroporto)
- Branches: dev, hml, main

### 💬 Fala Pronta - Explicando Git

> *"Agora preciso te explicar três conceitos que vão aparecer o tempo todo na sua jornada. Prometo que vou traduzir tudo pra linguagem humana!*
>
> *Primeiro: Git. O Git é tipo uma máquina do tempo para os seus arquivos. Imagina que você está escrevendo um livro. Aí você faz uma mudança grande num capítulo, mas depois se arrepende. Com o Git, você consegue voltar pra versão anterior como se a mudança nunca tivesse acontecido.*
>
> *Programadores usam isso o tempo todo porque criar software é um processo de muitas tentativas. O Git guarda o histórico de tudo, então você nunca perde nada."*

### 💬 Fala Pronta - Explicando GitHub

> *"Agora, o GitHub. Se o Git é a máquina do tempo, o GitHub é a nuvem onde você guarda essa máquina do tempo.*
>
> *Pensa assim: você pode ter fotos salvas no seu computador, certo? Mas se o seu computador quebrar, você perde tudo. Aí você usa o Google Fotos ou o iCloud pra guardar na nuvem. O GitHub é a mesma ideia, só que para projetos de programação. E tem um bônus: outras pessoas podem ver e colaborar com seus projetos."*

### 💬 Fala Pronta - Explicando Gitflow

> *"E por último: Gitflow. Imagina um aeroporto. Você não mistura os aviões que estão sendo consertados com os que estão prontos pra voar, né? Tem áreas separadas.*
>
> *No desenvolvimento é igual. A gente trabalha em 'pistas' separadas:*
> *- **dev**: é a oficina de manutenção. Aqui a gente mexe, testa, quebra, conserta.*
> *- **hml**: é a pista de teste. O avião sai da oficina e faz uns voos de teste antes de levar passageiro.*
> *- **main**: é a pista principal. Só decola daqui o que está 100% pronto.*
>
> *Assim a gente nunca bagunça o que já está funcionando enquanto cria coisas novas."*

### 💬 Fala Pronta - Preparando para Importar

>

É como ir numa loja, pegar o produto e trazer pra casa. Só que a loja é a internet e o produto é gratuito."*

### Passo a Passo Detalhado

#### PASSO 1: Abrir o Terminal no Antigravity

### 💬 Fala Pronta - Abrindo Terminal

> *"Primeiro, vamos abrir o Terminal. Lembra dele? A tela preta na parte de baixo. Pra abrir, você pode ir no menu 'Terminal' lá em cima e clicar em 'New Terminal'. Ou, se quiser ser mais rápido, aperta Ctrl + aspas simples no seu teclado.*

#### PASSO 2: Clonar o Repositório

**Comando:**
```powershell
git clone https://github.com/Victorlllima/shark-method.git $HOME/.gemini-shark-temp
```

### 💬 Fala Pronta - Explicando o Comando

> *"Agora você vai digitar um comando. Não precisa decorar, só copia exatamente o que eu vou mostrar na tela.*
>
> *Esse comando faz o seguinte: ele vai no GitHub, pega todo o conteúdo do método S.H.A.R.K. e baixa pra uma pasta temporária no seu computador. É o famoso 'clonar' - você está fazendo uma cópia do projeto pra você."*

#### PASSO 3: Executar o Script de Instalação

**Comando:**
```powershell
cd $HOME/.gemini-shark-temp; .\install.ps1
```

### 💬 Fala Pronta - Instalando o Método

> *"Perfeito! Agora a gente precisa dizer pro computador: 'Olha, pega o que você baixou e instala direitinho no lugar certo'.*
>
> *Pra isso, a gente vai rodar o script de instalação que já vem junto no pacote. Copia esse segundo comando e cola no terminal. Ele vai organizar tudo automaticamente pra você."*

#### PASSO 4: Reiniciar o Antigravity

### 💬 Fala Pronta - Finalizando

> *"Maravilha! Agora a gente precisa reiniciar o Antigravity pra ele reconhecer as novidades. É tipo quando você instala um aplicativo no celular e ele pede pra reiniciar.*
>
> *Fecha o programa completamente e abre de novo. Quando ele voltar, o método S.H.A.R.K. já vai estar instalado e funcionando."*
